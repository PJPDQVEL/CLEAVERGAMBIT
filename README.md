# CLEAVERGAMBIT
Cleaver Gambit é um jogo independente de ação e sobrevivência em pixel art, com elementos de roguelite, progressão por níveis, armas com propriedades distintas e um sistema de cartas inspirado na filosofia.
O jogador controla um pequeno guerreiro armado com um cutelo, enfrentando ondas de inimigos em uma arena. O objetivo é sobreviver, eliminar adversários, evoluir e adquirir melhorias que alteram as possibilidades de combate.
